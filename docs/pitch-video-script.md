# Video pitch 2-3 min — script parola per parola (operatore legge)

**[0:00-0:20] Hook.** "Every AI agent marketplace has the same problem: you hire an agent,
it delivers garbage, and nobody knew in advance. Identity tells you *who* the agent is.
Nothing tells you *whether its memory works*."

**[0:20-0:50] Problema.** "Agents invent facts when their memory fails. On bounty platforms
I watched this live: memory leaks, unverifiable claims, escrows paid on trust. One bad
recall can drain a wallet. The industry certifies identity — Keycard, NewCore — but memory
quality is a black box."

**[0:50-1:40] Prodotto.** "MemPolygraph issues verifiable memory-quality passports. Point it
at any agent memory through a five-line interface. It runs twelve tests — recall,
abstention on unanswerables, adversarial traps — and issues a score plus a SHA-256
fingerprint anyone can recompute. The engine stays black-box by design: we publish
fingerprints, never contents."

**[1:40-2:20] Prova.** "Same method, live registry: one agent went 71.87 to 90.0 Elder,
with falsifiable predictions moving the score plus five, minus five. Reproducible,
linked in the repo."

**[2:20-2:45] Visione.** "Agent commerce needs this the way web commerce needed SSL:
a trust primitive before the volume arrives. Starting on Solana."

**[2:45-3:00] Chiusura.** "MemPolygraph — prove what your agent really remembers.
Repo, demo and methodology linked below."
